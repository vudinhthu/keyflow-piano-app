# Salamander Grand Piano

Original recordings: **Alexander Holm**, Salamander Grand Piano v3.

License: [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

Original instrument/source: https://github.com/sfzinstruments/SalamanderGrandPiano

Web MP3 edition distributed by Tone.js: https://github.com/Tonejs/audio/tree/master/salamander

KeyFlow includes 21 existing web MP3 files covering C2–C7, one dynamic layer. The files are unmodified; pitches without a dedicated recording are generated by Tone.Sampler pitch shifting. This is a subset of the source library, not the full 16-layer SFZ instrument. No endorsement by the author is implied.

The manifest records source URLs, byte sizes and SHA-256 digests for the exact downloaded files. Run `pnpm samples:verify` to validate local assets. Future downloads must compare the manifest because the upstream master branch can change.
